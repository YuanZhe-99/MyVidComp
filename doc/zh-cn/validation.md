# 输出验证

每个转换出的临时输出在被提交或复用前，都要与源（hardware 模式适配时则与显式适配目标）验证。验证对输出运行 `ffprobe`，逐项比较下列属性。

## 主视频检查

| 检查 | 规则 |
|---|---|
| 编解码器 | 输出必须为 `av1` |
| 时长 | 必须有效（大于零） |
| 分辨率 | 宽/高必须与源完全一致 |
| 帧率 | 必须存在一组源/输出帧率对在容差内匹配（见下） |
| 像素格式 | 必须与源（规范化后）或显式适配目标一致 |
| 色彩元数据 | 源中已知时，range/space/transfer/primaries 必须一致 |
| 显示元数据 | SAR/DAR 数值容差比较；field order 必须一致 |
| 色度位置 | 更强元数据验证通过时，AV1/MP4 缺失报告为提示性；显式变更仍失败 |

帧率验证接受配对匹配：源与输出的名义帧率对，或源与输出的平均帧率对，以小容差比较。这吸收封装可能引入的平均/名义帧率漂移，同时仍拒绝真实的帧率变化。

SAR/DAR 以数值小容差比较，因为 FFmpeg 可能改写等价的 MP4 有理数（如近 1:1 的 SAR 值）。

## 流签名检查

输出流布局必须与期望的映射流签名一致：

- 流数量相同
- 各位置类型相同
- 第一个视频流必须为 `av1`
- 其他每个流必须保持精确的源编解码器

已确认的章节承载轨被排除出期望签名（见 [chapter-carrier.md](chapter-carrier.md)）。

## 章节语义

章节验证仅适用于已确认承载轨源：

- `ConfirmedMeaningful`：输出章节数量、起点/终点时间戳（0.05 秒容差）和精确标题必须与源章节一致。
- `ConfirmedEmpty`：输出必须不含任何章节。

普通源没有强制章节映射，因此没有章节验证。

## 修复与复用分类

验证失败分类：

- **可重封装修复**（AV1 色彩/色度元数据缺失）：可执行元数据修复重封装，其会重新探测并重新映射临时输出自身的实际流索引。
- **临时输出不可用**：无可读视频流或编解码器错误——临时输出被删除（仅限匹配 MyVidComp 临时命名的文件），绝不复用。
- **不匹配**：仅在编码器尝试循环内对严格输出不匹配可重试。

缓存的临时输出只有在同一验证路径通过后才可复用。

声明见 [functions/validation-commit.md](functions/validation-commit.md)。
